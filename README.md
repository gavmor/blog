# Gavin Morgan's blog

A small static blog intended for `https://www.gavmor.com/blog/`. It uses [mdsite](https://benchristel.github.io/mdsite/) for the page template and static files, and [marss](https://github.com/benchristel/marss) for the RSS feed and matching post anchors. Nothing in the diary is included or copied automatically. Only put material here that is approved for publication.

## Install, build, and preview

Requires Node.js 20 or later, npm, and Python 3 for the optional local server.

```sh
cd ~/Documents/blog
npm install
npm run build
npm run serve
```

Open <http://localhost:18765/>. The build recreates `dist/` from scratch, so do not keep hand-edited files there. It does not deploy anything. The feed is at `dist/feed.xml`; its links intentionally point to the eventual public site rather than the local preview.

## Write a post

Edit `src/index.md`. Remove “No posts yet.” when adding the first entry. Add each post as a level-two heading with a unique date and title, newest first; its body continues until the next level-two heading. For example:

```markdown
## 2026-11-04: A title

The text of the post goes here. Use **Markdown** as usual.

### A subheading

More text.
```

Use level-three headings for subsections, since marss treats every level-two heading as a separate feed item. Dates in `YYYY-MM-DD` format become RSS publication dates. Use absolute URLs for links and images in posts so they also work in feed readers. Keep the `@marss` metadata comment: it sets the feed title, description, and public URLs. If the final canonical hostname or path changes, update both URLs there. The HTML is generated by marss before mdsite wraps it, so feed links point to the same heading IDs as the published page. Rebuild after editing.

`src/style.css` controls the appearance; `template.html` contains the page shell and RSS discovery link. Other files placed under `src/` are passed through mdsite as static assets, subject to its file handling. The relative stylesheet and feed URLs work both in the local preview and under `/blog/`.

## Publishing

Push to `main` in the `gavmor/blog` repository to build and deploy via GitHub Actions. GitHub Pages serves this project at `/blog/` under the existing user site's custom domain. Review posts for private material before pushing; never publish diary entries without explicit permission.
